📦 Package & Class Architecture UML Component Diagram

Telegram Bot Layer

  • 17 slash commands + 14 callback action types
  • python-telegram-bot v22.x with long polling
  • APScheduler job queue (hourly + breaking)
  • Graceful SIGTERM/SIGINT shutdown
  • HTTP health server (stdlib, port 8080)

Core Application

  • SQLite (WAL) with schema migration
  • Pluggable state backend: in-memory vs Redis
  • NewsData.io client with caching + retry
  • Multi-source merge: API + RSS
  • Near-duplicate clustering + trust ranking

Key Design Decisions

  • Batched digests — one API call per (country, category)
  • Whole-word search (no "AI" matching "airport")
  • Breaking alerts with daily cap + quiet hours
  • 3-step onboarding (region → category → subscribe)
  • Free-tier budget protection (configurable limit)
